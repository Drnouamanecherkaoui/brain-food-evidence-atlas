# Brain Food Evidence Atlas

Static website for the NEUROFUEL LAB research program behind the Brain Food brand: graded, citation-verified human
evidence on nutrition and cognitive performance, with safety, regulatory and product analysis.

This repository contains only the built site. It is generated by `tools/build_site.py` in the research project and
deployed with `tools/deploy_site.sh`; edit the source there, not here.

Current build: 15 ingredient monographs, 198 graded outcome rows,
513 unique references, version `7cbff3eae9` (20261025191129 UTC).

Draft research. Not medical advice and not product claims. Search-engine indexing is disabled (`robots.txt` and a
`noindex` meta tag) until the research has been independently reviewed.
